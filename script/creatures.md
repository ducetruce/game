## thistlecalf -- Thistlecalf
<!-- creature thistlecalf -->

### name
- Thistlecalf

### description
- A yearling grazer, matted to the shoulder in burr-thistle it has stopped trying to shed. Bolts at a raised hand.

## cairnling -- Cairnling
<!-- creature cairnling -->

### name
- Cairnling

### description
- Seven stones stacked by nobody, in an order it will restore if you knock them down. It waits for you to finish.

## skirling -- Skirling
<!-- creature skirling -->

### name
- Skirling

### description
- Audible well before it is visible. Hunts the high air over the moor and comes down only to argue.

## sloughback -- Sloughback
<!-- creature sloughback -->

### name
- Sloughback

### description
- Carries a hand's depth of the fen on its back, complete with its own small weather. Moves once a minute and regrets it.

## emberwick -- Emberwick
<!-- creature emberwick -->

### name
- Emberwick

### description
- Burns from a wick that runs its whole length. It is aware of how much of itself is left and does not discuss it.

## gloamkin -- Gloamkin
<!-- creature gloamkin -->

### name
- Gloamkin

### description
- Easier to see from the side than head-on. Keeps to the hour between the sun going and the dark arriving, and is thinner outside it.

## moorhound -- Moorhound
<!-- creature moorhound -->

### name
- Moorhound

### description
- Runs the ridgeline in a straight line for hours. Will not be driven off, and will not be first to look away.

## reedwitch -- Reedwitch
<!-- creature reedwitch -->

### name
- Reedwitch

### description
- Stands in the reed beds at the height of the reeds and moves when they move. What it is doing there, it has been doing for some time.

## rushwither -- Rushwither
<!-- creature rushwither -->

### name
- Rushwither

### description
- Green things grow back along the dry channel, and this is what they grow into. It leans away from you at the exact speed you approach.

## drownbell -- Drownbell
<!-- creature drownbell -->

### name
- Drownbell

### description
- It hangs a hand's width under the surface and does not rise for anything. Whatever the mere is holding, this was here before it.
